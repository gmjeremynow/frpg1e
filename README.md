# 1e FRPG (Table Edition) for Foundry VTT V14

A private-table game system (v0.31.0) that runs 1e FRPG straight off the book tables.

## Install (Molten or any self-hosted Foundry)

1. Your server must be on Foundry **V14**. Back up your user data before upgrading.
2. Unzip `frpg1e.zip` so the folder lands at `Data/systems/frpg1e/` (Molten: use the file manager or SFTP and upload into `Data/systems`).
3. Restart Foundry, create a world, and pick **1e FRPG (Table Edition)**.
4. On first launch the GM is offered the book compendia: weapons, armor (PHB/DMG plus UA bronze, field and full plate and the buckler), 99 PHB equipment items, the 414 PHB spells, the 224 UA spells and cantrips, the 40 PHB psionic disciplines, 588 DMG and UA magic items, the 53 DMG gems and the 43 DSG/WSG nonweapon proficiencies. You can rebuild them any time from *Configure Settings → 1e FRPG → Import Book Compendia*. Updating from an earlier version offers the rebuild again.

The weapon table on the Combat tab prints the score needed against AC 10 down to AC 0, as on the TSR record sheet.

## Choices made where the books are silent or disagree

- **Damage ranges to dice.** The books print ranges (2-7), not dice. Each range is converted by one fixed rule (`rangeToFormula` in `module/tables.mjs`) that always reproduces the printed range. Two ranges have more than one common dice choice: 3-9 is rolled as 3d3 and 3-12 as 3d4. Every formula is editable on the item.
- **Monk combat table.** The PHB says monks attack on the thief table; DMG matrix I.A lists them with clerics. The DMG table is the default; change it per character on the Record tab.
- **Multi-class attacks** use the best matrix of the character's classes. The DMG states the best-of rule for saving throws; I did not find it stated for attacks.
- **Armor types below AC 0** use the UA AC 0 column.
- **Monsters under 1 HD** save at level 0 (fighter 0 row); 1-1 HD saves at level 1.
- **Wisdom bonus spells and spell failure** apply to clerics and druids (Wisdom Table II, as corrected by the errata in The Dragon #35). Paladins and rangers can be given extra slots by hand on the Magic tab.
- **Dexterity save adjustment** uses the Dexterity Table I defensive figure with its sign flipped (dex 18 = +4 to the save), only when the save dialog's "can be dodged" box is ticked.
- **Coins are not counted** toward encumbrance.
- **Bard 20th level** begins at 1,800,001 XP. The PHB prints 1,000,001, which falls inside the 19th level range.
- **Cavalier weapons of choice past 13th level.** UA gives the bonuses to 13th, then says the progression "increases in a similar fashion". The system continues +1 every 6 levels for each weapon (lance 19th, sword 15th, horseman's weapon 17th). Edit `cavalierChoiceBonus` if you rule otherwise.
- **Barbarian climbing and hiding** use the base thief table value for the stated level, with no race or dexterity adjustment. The thief table ends at 17th.
- **Discipline costs need both pools.** PHB p.111 says a strength point equals 1 attack and 1 defense point. Requiring both pools to hold the full cost, with no transfer between them, is a table ruling.
- **Body weaponry** armor class is treated like armor: dexterity and misc. adjustments still apply. It never stacks with conventional armor: any worn armor or shield turns it off (PHB p.111: the factors do not apply while armor and weapons are used). Multi-class characters use the most favorable eligible column (cleric, fighter or thief); no column is invented for monks or bards.
- **House ruling: level of mastery for multi-class characters** is the highest class level. The PHB says mastery equals "the level of experience" without saying which class counts.
- **Per-turn upkeep** is charged every 10 combat rounds from the round the discipline started.
- **DMG misprint:** table III.H prints "Hammer +2" for both 57-60 and 61-62. The UA reprint of the same table reads Hammer +1 for 57-60, which is used.
- **DMG items keep their DMG values.** Where the UA reprint of a DMG row prints a different x.p. or sale value (for example gauntlets of ogre power, horn of blasting), the DMG figure is kept; the UA tables are used for the UA-only items and for random rolls when the UA tables are chosen.
- **Base weapon for magic weapons** when the table does not say: long sword (the most common sword in both tables), long bow, light crossbow, footman's flail, mace and pick, medium horse lance, small shield. Each item says so in its description; change the statistics if another type is rolled.
- **Special "+N vs." bonuses** replace the normal bonus for both "to hit" and damage when chosen.
- **Gem worth table:** "roll again ignoring results above 8" (and "below 2") is read as: such a result on the repeat roll changes nothing and ends the rolling.
- **Jewelry values:** the DMG prints ranges (100-1,000 gp and so on). They are rolled with dice that reproduce each range exactly (1d10×100, 2d6×100, 3d6×100, 1d6×500, 1d6×1,000, 2d4×1,000, 2d6×1,000). Exceptional workmanship takes the piece to the top of its class, or to the next class if it is already at the top.
- **Bracers of defense** do not work with body armor; a shield still adds its bonus.
- **Magic armor movement:** DMG p.27 says magic armor moves at the next higher rate; DMG p.165 calls it virtually weightless. The system uses p.27.
- **Scroll spells:** levels outside a class's range (for example a 9th level cleric roll on the 2-9 rows) are reduced to the highest level that class has.
- **Restorative ointment** heals "9-12 points"; it is rolled as 1d4+8, which gives exactly that range.
- **Printed ranges with no dice** are rolled the same way as weapon damage (dice that reproduce the range exactly). Where no set of standard dice gives the range, one die of that size is used: dust of dryness 6-30 is 1d25+5, and the rod of rulership's 200 to 500 hit dice is 1d301+199.
- **"All 1's count as 2's"** (wand fireballs and cones, 6d6, "12-36") is rolled as written: each die below 2 counts as 2. The staff of thunder and lightning's 1s-and-2s-count-as-3s works the same way.
- **Staves at 8th level.** The DMG says staves function at 8th level and their fireballs and lightning bolts are "nominally 8d6"; staff of power cone of cold is 8d4+8 and magic missile fires 4 missiles, the staff of the magi wall of fire is 2d6+8, from the spell text at 8th level.
- **Amulet of the planes:** d12, plus 12 on a 4-6 on d6, is rolled as 1d24, which gives the same chances.
- **Order of results the DMG gives only as percentages** (efreeti bottle 10% insane, 10% three wishes; the elemental oil's four kinds) is the system's; the chances are the book's.
- **Chime of opening** charges: the DMG prints "20-80 (20 + d6 × 10)"; the formula is used, which gives 30-80.
- **Potions with no stated duration** use the DMG's general potion duration, 4 turns plus 1-4 (1d4+4).
- **Caster level for paladins, rangers and bards: Unknown** in the PHB text I have. The cast dialog prefills the character's level in that class; change it if you rule otherwise.
- **UA words broken across lines** ("detect-/able", "magic-/user") are rejoined using the books' own spelling of the word elsewhere; where the books never use the word, common compound prefixes (non-, half-, one-, and so on) keep their hyphen. The UA's stacked fraction in *giant insect* reads "1/8 HD".
- **PHB text is kept as printed**, including its own slips: *charm monster* runs two sentences together ("...a new saving throw versus the charm, the spell will affect from 2-8 1st level creatures..."), and *control weather* ends without a period.
- **Ability Checks** come from the DSG and WSG; the PHB, DMG and UA have no general Ability Check. The WSG's rules (18 cap, 19-20 fail) are used for d20 checks; the DSG's plain "roll the score or less" for checks made with other dice, since the WSG speaks only of the d20.
- **Proficiency Checks follow the WSG** (p.11-12): d20 plus modifiers at or under the ability score, scores above 18 count as 18, an unmodified 20 always fails and 19 fails unless the proficiency is improved. The DSG (p.23) describes the check differently in places ("a +3 makes a d20 roll of 12 equal to a 15", "a 3 or less ... fails"); the WSG, which says its system is the DSG's, is the clearer text.
- **Proficiency modifiers are stored as the WSG prints them** (added to the d20; negative is easier). The DSG prints the same numbers with the opposite sign (added to the ability score). The proficiencies in both books confirm it: boating DSG +1 / WSG −1, healing +2 / −2, riding +3 / −3, fire-building −1 / +1, fishing −1 / +1, direction sense +1 / −1. DSG-only proficiencies are converted the same way (weaponsmith −3 becomes +3).
- **Riding:** the DSG's *riding* and the WSG's *riding, land-based* are one item; the WSG says they are essentially the same.
- **Multi-class proficiency slots** use the class that gives the most of each kind; the DSG and WSG do not say. A bard adds the bard's slots (1/1 per 4 levels) to the best of the character's other classes ("As other classes").
- **Tracking proficiency for multi-class characters** uses the highest class level (WSG: "5% per level of the character").
- **Healing never lowers hit points** and stops at the maximum, except aid, which the UA text lets exceed it for the spell's duration (remove the extra points by hand when it ends).
- **Old race keys are the PHB defaults:** Dwarf = hill dwarf, Elf = high elf, Gnome = surface gnome, Halfling = stout (UA: mixed blood counts as stout), Half-elf = high elf descent. Existing characters keep working.
- **Exceptional strength rows in UA Table II** (18/50, 18/75, 18/90, 18/99) are read as "this score or more": 18/80 uses the 18/75 row. The UA's elf ranger rows are printed that way (18/01, 18/51, 18/76); the other sub-tables do not say.
- **Drow without Sex set** use the male columns, with a note; Sex reads M/Male or F/Female.
- **Ability ranges for sub-races** use the PHB stock's figures, except gray and valley elves' intelligence maximum of 19 (UA p.10). Where male and female figures differ and Sex is not set, only the higher maximum is checked.
- **Drow and deep gnome save bonuses are shown, not applied.** Drow: +2 vs. "magical effects" (which categories that covers is the DM's call). Deep gnomes: +2 vs. poison, +3 on all other saves; the UA does not say whether this replaces or adds to the gnome constitution bonus, so the sheet keeps the PHB gnome bonus and the note says to enter the UA bonus as your DM rules.
- **MM text is kept as printed in the Premium Edition PDF,** including its misprints (electric eel *No. Appearing* "7-3", winter wolf treasure type "1", hill giant "MO. APPEARING"). Fix any you like on the actor.
- **Ammunition stacks** are the units the price lists sell (12 arrows, 20 heavy quarrels, 20 sling bullets). Light quarrels are priced singly in the PHB and come as a stack of 20; sling stones have no price; UA prices hand crossbow quarrels at 100 gp without saying how many (stack of 1: set your own). Blowgun needles have no separate weight in UA.
- **Brawl uses UA System II** (the DMG pummel/grapple/overbear percentage tables are not used). Character size for overbearing: dwarves, gnomes and halflings S (as in the MM), others M. Exposure for stunning: no armor, leather or padded = exposed; full or field plate = unexposed; other armor semi-exposed; monsters by natural AC (7 or worse exposed, 2 or better unexposed). Helmets are not tracked. Monsters have no strength score: enter one in the dialog to roll a stun.
- **Monk surprise as a percentage**: when surprised, the lower half of the chance loses 1 segment and the upper half 2 (the PHB gives the chance, not the segments). The most favorable surprise chance among class and race applies. Morale checks are rolled for any actor; the DMG applies them to henchmen, hirelings and intelligent monsters (the dialog warns for non-intelligent ones).
- **Token bars** show when anyone hovers over a token (new actors, the book compendia, and world monsters and placed monster tokens still set to none when Apply Monster Art runs).
- **Token size** (a choice; the books give sizes S, M, L but no grid footprint): S and M monsters get a 1×1 token, L monsters 2×2: in the compendia, for new monsters, when a monster's Size is changed on its sheet, and (once, after this update, and with Apply Monster Art) for monsters and placed tokens already in the world. Change any single token by hand if you like.
- **Monster hit points:** fixed hit dice get the average (4½ per die plus adds); hit points printed as a range get its middle; Tiamat and Bahamut get their printed totals. Variable hit dice (dragons 9-11, hydra 5 to 12...) keep the default: roll them with the dice button (for dragons the MM sets hit points per die by age).
- **Attack column for tiny monsters:** a hit point spread of 1-7 attacks as 1-1 HD and anything smaller as "up to 1-1" (MM p.5: such spreads are less than a full die; 1-1 HD is 1d8−1). **Monsters given only in hit points** (demon princes, arch-devils, golems, beholder): the attack column is not stated (Unknown); the sheet asks you to set *Attacks as HD*.
- **Humans and demi-humans in the MM** (men, dwarves, elves, gnomes, halflings) "always use the matrix for humans" (MM p.5). The Monster sheet only has the monster matrix, so it shows that note; run them as characters if you want the human matrix.
- **Psionic ability given as a range** (mind flayer 241-340): the middle of the range is used for psionic strength; adjust or roll it.
- **Treasure multipliers** (Q ×5) multiply the coins, gems and jewelry found; the MM says only "larger treasures". **"1 (2) of each magic excluding potions & scrolls"** is read as one (two) item(s) from each of the other kinds on Table III (rings, rods/staves/wands, miscellaneous, armor, swords, misc. weapons). **Maps** are listed, not generated.
- **Experience points for monsters:** the MM gives none; the DMG formula is not applied. Enter XP on the sheet. MMII monsters carry their printed Level/X.P. value as text.
- **MMII source:** the MMII PDF is a page scan with an OCR text layer, which misreads many characters. Every stat block was checked against the page images and corrected by hand. Values the book itself misprints are kept as printed: Merrow XP "II/130", ordinary vulture XP "II/35/hp", thri-kreen damage "d41", giant raven XP "III/60+4", taer frequency "Very", hangman tree "61 hp/year", kelubar XP and blank % in lair, charonadaemon XP "+ 16 hp", ordinary squirrel XP "I/O" (letter O or zero cannot be told apart in the scan), salt water scrag size "L (10\" tall)". The smoke para-elemental has no Armor Class line in the book (AC field left at 10, marked *Not printed in MMII*). Two misplaced slashes were moved to the usual place (agathion "VII 1800/" and giant solifugid "V350"). Where the parser missed a multi-column stat block (deadly puddings, vultures), the columns were split by hand into separate actors. Lines the book leaves out stay empty (pedipalps have no Special Defenses line, the sandling no Special Attacks line, the soldier termite no Treasure Type).
- **FF source:** the FF PDF is page scans with no text at all, so it was read with OCR (tesseract). Every stat block was then checked line by line against the page images and entered by hand; spelling follows the book (ARMOUR, DEFENCE become the usual sheet fields). Values kept as printed: shocker *No. of Attacks* "11", huecuva XP "III/81 per hit point", throat leech XP "I/6", achaierai hit dice "Body 40 hits points". Multi-column stat blocks (garbugs, mephits, urchins) are one actor per column. Lolth and the styx devil keep the FF footnote on their XP (Material Plane form only).
- **FF descriptions (0.18.0)** are rewritten in plain words with the same rules: every number, range, die and table entry is kept. They were made from the OCR text, with doubtful words and numbers checked against the page images, and the jumbled OCR tables are rebuilt as proper tables (caterwaul agility, crypt thing teleport, devil damage, oriental dragon ages, githyanki and githzerai lairs, grimlock weapons, kuo-toa hit points and slaves, deep gnome elementals). Where the OCR could not be settled the text was left as printed; check the book for a doubtful word or number.
- **MM descriptions (0.19.0)** are rewritten in plain words with the same rules: every number, range, die and table entry is kept. The dragon age table, the Men magic item table and the dervish table are rebuilt as proper tables, stray illustration captions are dropped, and text split across a page break (vampire into giant wasp, yeti into zombie) is moved back to its own monster. Book quirks are kept and marked “as printed” (for example the su-monster psionic roll and the ochre jelly’s “Cold and attacks”).
- **Dragon #35 errata (0.20.0).** The official errata from The Dragon #35 (March 1980) is applied where our source printings lacked it: druids use Wisdom Table II (bonus spells and spell failure); magic-users scribe scrolls and make potions from 7th level and enchant items from 12th; druid *water breathing* is V, S; *explosive runes* saves “None or ½”; the reverse of *cure critical wounds* is *cause critical wounds*; demon type V is AC −7/−5; flesh golem moves 9”; wererat size S-M; giant strength is 19 to 24. The data fixes are in `tools/errata_d35.py`, which is safe to re-run after a data rebuild. The DMG errata and most MM errata were already in our source printings.
- **FF hit dice and hit points (0.21.0).** Every FF hit dice entry was checked against the page images. The hit point roll (the dice on a monster's Hit Points) now follows the book: fixed hit points (“22 hit points”) and hit point ranges (“1-4 hit points” = 1d4) roll correctly, the death knight uses d10s, ranges of hit dice and kinds (kuo-toa fixed hit points, tiger fly male/female/larva, leaders) are offered as a choice, parts tracked separately (achaierai legs, tentamort tentacles, whipweed stalks, cifal binding force) are rolled and listed on the card, and oriental dragons roll size and age (FF p.28), which also sets their attack column and saves. Entries with no hit points to roll (aleax, githyanki, githzerai, gorbel, hound of ill omen, trilloch) say why. Monsters given only in hit points save and check morale by the hit dice they attack as. The data settings are in `tools/ff_hp.py`.
- **MM hit dice and hit points (0.22.0).** Every MM hit dice entry was checked against the MM PDF, table columns included; all match. Hit points now roll the book's way: giants add their point spread (“12+2-7” = 12d8 + 2-7), fractions roll 1d4 (½) or 1d2 (¼), golems attack and save by the hit dice the golem section gives (9, 11, 14, 18), dragons and the dragon turtle roll size and age (MM p.29), and kinds the book names are offered as a choice (elementals by conjuring method, giantesses, flightless birds, herd animals, hydra heads, mimics, rhinos, sea horses, treant sizes, titans, dire wolf or worg). Any other range of hit dice (“3-8”, “12 to 36”) asks which, since the book gives no rule, and the choice sets the attack column and saves. The beholder's ten eyestalks are rolled and listed separately. The data settings are in `tools/mm_hp.py`.
- **Rolling ability scores (0.31.0).** A Roll 4d6 button in the Abilities box (characters and NPCs) rolls 4d6, drops the lowest, six times and posts the dice (dropped die struck out), the six scores and their total to chat (DMG p.11, Method I). It does not change the sheet. For a macro: `game.frpg1e.rollAbilityScores()`.
- **NPC roles (0.30.1).** Roles now cover NPCs who serve no one: independent (the new default), patron or employer, rival, enemy or villain, townsfolk or bystander, and ally. Loyalty, liege and wages appear only for roles that serve a liege (henchman, hireling, man-at-arms, associate, ally), as the DMG loyalty rules cover henchmen, hirelings and allied creatures; other NPCs use the 50% morale base.
- **NPCs (0.30.0).** A new actor type, NPC, uses the same rules as characters (classes, levels, abilities, saves, spells, thief skills, proficiencies) on a compact sheet: abilities, saves, class rows, weapons, armor, thieving and class abilities on one page. NPCs start at 0 level (fighter 0 row for attacks and saves, PHB p.105), with a button to roll a man-at-arms' 4-7 hit points (DMG), and tokens start unlinked and neutral so one actor can stand for several guards. A Service box records role, occupation, wages and liege (a character in the world, or name, charisma and alignment by hand) and works out loyalty from the DMG p.36-37 tables: base 50%, the liege's charisma, the modifier groups, the liege's alignment, one special penalty and one bonus, with the loyalty band shown. The Loyalty button rolls a check against it (with the DMG's typical situations and their failure results), and Morale uses the loyalty score.
- **Setting modules (0.29.0).** Optional add-ons (such as the Krynn module) can register races, classes and spell tables through `game.frpg1e.api` during the `frpg1e.init` hook, hide races from the list, and add notes to characters through the `frpg1e.prepareCharacter` hook. A registered race carries its own class limits, multi-class list and ability ranges. A class may be built on a core one (`as: "cleric"`), so it turns undead, rolls low-wisdom spell failure and gets wisdom bonus spells like the class it is built on. With no module switched on, nothing changes.
- **Monster attack buttons (0.28.0).** Buttons are now read from the whole Damage/Attack line, not just split at “/”. Alternatives printed with “or” get their own buttons with an *or* between them (vulchling: 2-5 *or* 1-4, 1-4); lists such as “1-6, 1-8, or 1-10 according to size” become one button each; notes stay off the buttons (“1-4 each” is 1-4, “2-12 + poison” is 2-12); “(x4)” shows as ×4; labels like “(bill)” name the button; printed bonuses (“+7”, “(+6 strength bonus)”) are added to the damage; “by weapon type” gives a Weapon button that rolls to hit and says the damage is by the weapon used; “Nil” and “See below” give no buttons. A monster whose hit dice are a range (black willow 12-19) says it attacks by the lowest until Attacks as HD is set (rolling its hit points sets it). Buttons you edited are kept as they are.
- **Monster art folder (0.27.0).** The default folder is now `frpg1e_monster_art` (was `Monster Art`). A world whose setting still says `Monster Art` is switched to the new name. Existing art is not moved: put the images in the new folder and run Apply Monster Art.
- **Generic names and lore (0.25.0, 0.26.0).** 21 magic items named after characters use generic names (for example Underwater Apparatus, Orbiting Stones, Eye and Hand of the Lich, Blessed Spellbook, Prison of Binding, Ring of Arcane Knowledge, Sword of Betrayal), in the item compendium, the DMG treasure tables and every cross-reference. The lore of the Eye and Hand of the Lich, the Mask of Concealment, the Quill of Forgery and the Marvelous Nightingale no longer names characters; the Sword of Betrayal has its own history as a blade that turns trusted servants against their masters. The Floating Disc and Mirror of Life Trapping text no longer names wizards. Mechanics are unchanged. The lists are in the build tools (`tools/spell_names.py`, `tools/scrub_lore.py`), which the packaging step runs.
- **Generic spell names (0.24.0).** The 29 PHB and UA spells named after wizards use generic names (for example Floating Disc, Clenched Fist, False Trap, Arcane Sword, Compulsive Discourse, Spell Recollection, Magic Disjunction), and every mention in spell, item and monster text changed too. The magic-user Spell Immunity (8th level) shares its name with the UA cleric spell Spell Immunity (4th level).
- **Giant frogs (0.23.1).** The giant, killer and poisonous frog entries had no description (the MM text was never imported); they now have the full MM p.41 text in plain words, and giant frog hit points offer the three sizes the book describes.
- **MMII descriptions (0.23.0).** Every MMII monster description is rewritten in plain words: same rules, every number, range, die and table entry kept. Doubtful OCR readings were checked against the page images; tables the scan garbled were rebuilt from the images (minimals, shades, solar powers, snake poison, termites, webbirds, modron castes and telepathy ranges, and others), and the hordling tables that were missing are now there. Italic “+1” that the OCR read as “+7” is corrected. Book oddities are kept and marked “as printed”.
- **MMII hit dice and hit points (0.23.0).** Every MMII hit dice entry was checked against the page images; all match the book, including odd ones kept as printed (pyrolisk “43”, hangman tree “61 hp/year”). Hit points roll the book's way: hit points written as “hp” or “h/p” are used as given; cloud and mist dragons roll size and age, and the shadow dragon rolls size on d% (25/50/25) with +1 hit point per die, all saving as hit points ÷ 4 hit dice at 5 or more per die (MMII p.56); the faerie dragon's hit points follow its age table; kinds and leaders the book names are offered as a choice (azer, barghest growth, cambions, diakk, fomorians and their young, hordlings, para-elementals, quasi-elementals, time elementals, yuan-ti, merrow, derro, termite king and queen, and more); the froghemoth's tentacles and tongue and the wolf-in-sheep's-clothing's roots and eyestalks are rolled separately. Where the book gives no way to roll (shade, vagabond, phantom, pseudo-undead, swanmay, minimal, hangman tree, pyrolisk), the card says why. Quickling half dice and the yochlol's “6 (1d10)” are not explained in the book: the choices say so. Any entry that is not a single plain hit dice value now uses Attacks as HD for saves and morale. The data settings are in `tools/mm2_hp.py`.
- **Assassination against monsters:** the DMG table is by the victim's level. For a targeted character the highest class level is filled in; for anything else type the level the DM rules.
- **Ranger giant class damage** (+1 per level) is listed, not added to damage rolls, since the sheet cannot tell what the target is. Add it on the damage card.
- **Psychic crush.** The DMG IV.D footnote says "User may use only defense mode G, Thought Shield." It is quoted on the card rather than enforced.

## Known gaps

- **Thief-acrobat hit points after 12th level: Unknown.** I did not find the rule in the UA text; the level-up roll warns instead of guessing. Enter them by hand.
- **Splint mail's thieving category: Unknown.** UA Thieves Table II does not list it, so the armor ships unset and the sheet warns until you pick one.
- Insanity and feeblemind (no saving throw adjustment printed in IV.C) are not handled.
- **Chain and plate barding cost: Unknown.** The prices are not legible in the PHB source text.
- Items whose bonus varies (rings and cloaks of protection, bracers of defense, sword of dancing, quarterstaff, buckle knife, dagger of throwing, axe of hurling) need the rolled bonus set on the item. Where the description has the table, *Determine type (when found)* rolls it; enter the result on the item.
- A few tables inside magic item descriptions were printed in columns and come out jumbled where the rewrite could not rebuild them with certainty; the item's page reference is given.
- Healing that is not a single roll is left to the text: paladin lay on hands, goodberry, dispel exhaustion, the ring of regeneration and the bead of curing on a necklace of prayer beads.
- Spells already on a character sheet keep their old description; drag fresh copies from the rebuilt compendium for the rebuilt text. Items and spells already on a character sheet before 0.4.0 do not have the catalogued dice (and before 0.3.1, the healing rolls); drag fresh copies from the rebuilt compendia, or type the roll into the item's *Healing roll* field.
- Dice that need a judgment to apply are rolled but not applied: the staff of swarming insects number (1 damage per 10 insects), hits from the wand of wonder's gem stream, rock damage plus a giant's strength bonus. Saving throws are not rolled for targets; use *½* for a made save.
- Oriental Adventures nonweapon proficiencies are not included (the book is not among this system's sources). The DSG swimming rules (p.12) and the equipment for proficiencies (p.56) are referred to but not reproduced.
- The weapon proficiency list does not set the *Prof* box on weapons; tick it on the Combat tab.
- **Thief-acrobat level limits for non-humans: Unknown.** UA Table II has no acrobat column. **Half-elf paladin level limit: Unknown** (Table I allows it for dark, gray and high elf descent; Table II has no column). The Race box says Unknown for these.
- Comeliness itself is not on the sheet; the Race box gives the racial adjustment only. Racial ability adjustments, drow and duergar light penalties, drow movement, and innate spells are listed, not applied.
- **Plain-words descriptions (0.16.0).** Every PHB spell, UA spell and cantrip, magic item, psionic power and DSG/WSG proficiency description is rewritten in plain words with the same rules: every number, range, duration, die and table entry is kept, reorganised into lead-ins, lists and tables. Gems were left as they were. Where the source text is incomplete or inconsistent, the description says so rather than filling the gap: Telempathic Projection is left incomplete in the PHB itself, so its entry carries a house ruling, marked as such (sense as empathy for 3 points with no save, or send for 1 point per level/hit die to contact plus 1 to send with a save vs. magic; the sent emotion's effect is the DM's call), and the sheet asks which mode when it is used; the Wand of Size Alteration states no duration; the Detection of Good/Evil chart skips fifth, seventh, ninth, eleventh and thirteenth levels of mastery; the Deck of Illusions suit names are not given, so its four sets are numbered; the Shape Alteration example (19 points) and the multiple-operation range rule (+50% each, "200%" for two) are kept as printed and flagged. The Molecular Manipulation table, which the source printed inside Dimension Walk, has been moved to Molecular Manipulation. Items and spells already in a world keep their old text; drag fresh copies from the rebuilt compendia.
- PHB and UA spell descriptions were rebuilt from the PDFs one column at a time (PHB in 0.4.1, UA in 0.4.2), so tables show as tables and lists as separate lines. A few two-line table headings show as two heading rows.

## Naming

From 0.16.3 the system, its sheets, compendia and the non-monster descriptions call the game "1e Fantasy RPG" (short form "1e FRPG") and the books "PHB", "DMG", "UA", "DSG" and "WSG". Monster descriptions keep the book wording. From 0.17.0 the system id is `frpg1e` (it was `adnd1e`) and the compendium ids start with `frpg1e-`. A world made with the old system will not open with this one: create a new world and pick 1e FRPG (Table Edition), and remove the old `Data/systems/adnd1e` folder.

## Development

The rules engine (`module/tables.mjs`, `module/rules.mjs`) has no Foundry dependencies. Its tests compare every cell of the DMG attack matrices against the book text and replay the DMG p.71 melee example.
